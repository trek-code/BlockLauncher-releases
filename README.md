# Block Launcher — releases

Downloads for **Block Launcher**, a Minecraft launcher for Windows: Microsoft sign-in, vanilla/Fabric/Forge/NeoForge instances, one-click server joining, and Modrinth/CurseForge mods.

**Download:** grab `BlockLauncher-<version>-portable.exe` from the [latest release](../../releases/latest). It's a single file with no installer.

Already installed? The launcher's **Updates** tab finds new versions here and installs them for you.

Each release also includes `latest.json` with the exe's SHA-256, which the launcher checks before installing.
